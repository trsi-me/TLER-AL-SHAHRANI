# TLER AL-SHAHRANI

موقع شخصي ثابت لصفحة واحدة طويلة، مع صفحة روابط في المجلد `links`. المؤلف المكتوب في الميتا: تلر الشهراني. الصفحة الرئيسية تعرض تعريفا وخدمات وأعمالا ومراجعات ونموذج تواصل. لا خادم ولا قاعدة داخل المجلد.

# الجزء الأول - التعريف والفهم العام

## 1. ما هو المشروع؟

ملف `index.html` عربي الاتجاه يعرّف الزائر بمحمد آل مبارك آل محمد العوسجي البجادي الشهراني، من بيشة، وسنة الميلاد المكتوبة 2009م. الشعار والأعمال والشهادات صور في `assets/images`. الخط IBM Plex Sans Arabic في `assets/fonts`.

مجلد `links` صفحة مستقلة بعنوان كل روابط تلر الشهراني، وفيها أزرار إلى مواقع وحسابات.

## 2. لماذا يوجد هذا المشروع؟

نص الصفحة يقدّم خدمات وسابقة أعمال ودعوة للتواصل. وثيقة مشروع منفصلة غير موجودة.

## 3. من يستخدمه؟

زائر يقرأ الصفحة أو يرسل نموذج التواصل. حسابات داخل الموقع غير موجودة.

## 4. ماذا يستطيع النظام أن يفعل؟

أقسام `index.html`:

| المعرف | المحتوى |
|---|---|
| `#home` | ترحيب بالاسم |
| `#about-me` | نبذة، وبطاقات منها 11 شهادة و34 ثغرة |
| `#partners` | شريط شعارات |
| `#services` | خدمات: الأمن السيبراني، البرمجة، خدمات طلابية، صناعة المحتوى، التسويق، التصميم، أخرى |
| `#works` | أعمال، والنص يقول عدد الأعمال 16 |
| `#reviews` | مراجعات |
| `#contact` | بطاقات تواصل ونموذج رسالة |

نوافذ منبثقة في `script.js`: شهادات عبر `#certsBtn` و`#popup`، وثغرات عبر `#bugsbtn` و`#bugsPopup`، مع أسهم `#prevBtn` و`#nextBtn`.

قائمة الجوال وسهم العودة للأعلى بنفس أسلوب فتح وإغلاق القائمة.

نموذج `#message-form` حقوله: `user_name` و`user_email` و`user_msg`. الزر يستدعي `sendMail()`. EmailJS مهيأ في آخر `index.html`. مفاتيح التهيئة لا تُنسخ هنا. Google tag موجود في الصفحة كذلك.

أعمال ظاهرة كعناوين في الصفحة، ومنها: EncodeIt، GYAITR، TLER THE RIPPER، DAK-TS، Hrack، تبصِرة، متجر إلكتروني، منصة منامي، ChatBot ZS، مريومة، AutoMechX. بعض العناوين تشير إلى حالة مثل متوقف أو ملغي داخل النص نفسه. معرفات الكتل ليست متسلسلة بالكامل (`project1` ثم `project2` ثم `project4` وغيرها).

`links/index.html` أزرار إلى: الموقع الشخصي `https://trsi-me`، المتجر `https://trsi-sa.shop`، برنامج التسويق `https://tler-rewards.org`، قناة تيليجرام المجتمع التقني العربي، البريد `Contact@trsi.me`، الهاتف الظاهر `+966573806901`، وشركة مِنصاد `https://minsad.com`، وحسابات أخرى في بقية الملف منها PayPal. هذه روابط منشورة في الصفحة.

أيقونة التبويب في الرئيسية: `assets/images/‏‏My Logo Without Bg.icon`. صفحة الروابط تستخدم المسار نفسه نسبيا من مجلد `links`، بينما ملف الأيقونة موجود تحت `assets` في المجلد الأب.

ملف `assets/files/Visual ID Lareez.pdf` موجود.

## 5. كيف يعمل النظام؟

```text
المتصفح
  -> index.html + style.css + script.js
  -> صور وخطوط محلية
  -> CDN: Font Awesome وEmailJS وgtag
  -> links/index.html صفحة روابط منفصلة
```

## 6. أمثلة واقعية

### إرسال رسالة

1. الزائر يكتب الاسم والبريد والنص.
2. الضغط يشغّل `sendMail()` من السكربت المرتبط بالصفحة.
3. EmailJS محمّل في HTML. نجاح الإرسال يعتمد على تلك المكتبة وعلى الشبكة. خادم بريد داخل المجلد غير موجود.

### فتح الشهادات

الضغط على `#certsBtn` يظهر `#popup` و`#overlay` ويمنع التمرير بإضافة صنف `no-scroll`. الإغلاق يعيد التمرير.

### فتح صفحة الروابط

فتح `links/index.html` يعرض الأزرار. الصور داخلها تشير إلى `assets/images/...` نسبة إلى مجلد `links`.

## 16. Tech Stack

الشجرة في المعمارية. عدد صور `assets/images` كبير ويشمل شعارات أعمال وشركاء ولقطات. أسماء الملفات هي مرجع الأصول، وليست سرد ميزات إضافية.

## 18. Frontend

صفحة طويلة متعددة الأقسام (MPA من صفحتين: الجذر و`links`). الاتجاه RTL. القائمة للجوال تخفي تمرير الجسم عند الفتح. مراقب `IntersectionObserver` لعناصر `fade-in-*`. المعرض والنوافذ في `script.js`.

أيقونة التبويب مضافة في الصفحتين عبر `rel="icon"`.

- التقنيات: HTML وCSS وJavaScript وCDN.
